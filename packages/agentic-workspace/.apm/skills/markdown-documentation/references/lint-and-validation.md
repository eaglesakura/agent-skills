# Lint・検証・よくある修正

ドキュメント作成・更新後に確認する。自動修正は `markdown-fix` を併用する。

## 実装との整合性

* ディレクトリ構成・ファイルパスが実在と一致すること
* 引用コードが最新実装と一致すること

## よくあるリンターエラー

### 見出しの重複（MD024）

* 同じ見出しが複数あるとエラーになる
* 文脈を足して一意にする（例: 「補足」→「package分離の補足」）

### コードブロックの言語タグ（MD040）

* フェンスには必ず言語名（`dart` / `bash` / `text` / `yaml` / `mermaid` 等）
* ディレクトリ構成は `text`

### コードブロック前後の空行（MD031）

* フェンスの前後に空行を置く

### ベア URL（MD034）

* `<https://example.com/>` の形式にする

### リスト（MD007 / MD004）

* インデントは 2 スペース
* 箇条書きは `*`（`-` に統一しない）

### 連続空行（MD012）

* 空行の連続は 1 つまで
