# 計画の実装

## 概要

このコマンドは、事前に構築された実装計画を元に、実装の反映を行うものである.

* Coding-Commandsのステップ3である
  1. `/coding.requirement`
  2. `/coding.design`
  3. `/coding.execute`

## 入力値

コンテキストから、下記を判断する

* [ ] 事前に作成された計画ファイル  
* [ ] 計画内における作業範囲
  * 指定がなければ、すべての作業

## 作業手順

**`指定された計画ファイル内の作業範囲` を、下記の内部ステップに基づいて実行する**

### 内部ステップ1. 準備

* [ ] 計画ファイルをロードする
* [ ] ユーザーに対し、次の作業範囲を通知する

    ```text
    ユーザーによる計画実行の承認が行われました。
    計画モード・詳細設計モードのハーネスは解除され、実コードの修正を行います。

    {実行範囲}を実行します。
    ```

### 内部ステップ2. 実行

* [ ] `/coding-assistant.junior-engineer` Sub Agentを使用し、テンプレートに従った作業指示を与える

  ```markdown
  # 作業指示: [{作業ファイルタイトル}]({path/to/plan.md})

  ## 作業内容

  * {ステップXXXX} を完了させる
  * {ステップYYYY} を完了させる

  ## 品質確認

  * 修正したコードに関連するコードコメントの追加・更新を行う
  * Formatter, Analyzerによる機械的な品質保持を行う

  ## 結果返却

  <!-- 
  プロジェクトのチェックリストルールに従い、✅等を返却する
   -->

  [ ] {ステップXXXX}
  [ ] {ステップYYYY}
  ```

* 問題が発生したステップがある場合、`/coding-assistant.senior-engineer` に作業を引き継ぐ

  ```markdown
  # フォローアップ指示: [{作業ファイルタイトル}]({path/to/plan.md})

  * ジュニアエンジニアが作業を完遂できなかった
  * 作業を継続し、完了させること

  ## 作業内容

  * {ステップXXXX} を完了させる
  * {ステップYYYY} を完了させる

  ## 品質確認

  * 修正したコードに関連するコードコメントの追加・更新を行う
  * Formatter, Analyzerによる機械的な品質保持を行う

  ## 結果返却

  <!-- 
  プロジェクトのチェックリストルールに従い、✅等を返却する
   -->

  [ ] {ステップXXXX}
  [ ] {ステップYYYY}
  ```

* [ ] 返却された結果を統合し、計画ファイルのチェックリストを更新する
* [ ] ユーザーに対し、実行内容のサマリを通知する

    ```text
    {XXXXのステップをしました}
    
    {作業内容}
    
    {残作業}
    ```

### 内部ステップ3. フォローアップ

* [ ] `/coding-assistant.senior-engineer` Sub Agentを使用し、 `コーディング規約に沿ったコード` となるようにフォローアップを依頼する

  ```markdown
  # 品質担保指示: [{作業ファイルタイトル}]({path/to/plan.md})

  ## 作業内容

  * 対象ファイル一覧を確認し、コード品質の確認を行う
    * コメント粒度・内容が、プロジェクト方針と一致すること
    * コメント内容が適切でない（古い内容）の場合は、適切に更新すること
    * Formatter, Analyzerによる機械的な品質マネージメントを実施すること

  ## 品質確認

  * 修正したコードに関連するコードコメントの追加・更新を行う
  * Formatter, Analyzerによる機械的な品質保持を行う

  ## 結果返却

  <!-- 
  プロジェクトのチェックリストルールに従い、✅等を返却する
   -->

  [ ] {path/to/file}
    * {Formatter, コメント追従, 等の作業内容}
  ```

* [ ] 実施された内容に基づき、計画ファイルのチェックリストを更新する
* [ ] ユーザーに対し、下記の旨を告げる

    ```markdown
    {完了したステップ}

    {作業内容のサマリ}

    実装内容を確認し、次のステップに進むか、計画を調整するか指示をしてください。
    計画ファイルは [{ファイル名}](path/to/markdown.md) です。

    {次の作業ステップ}
    {作業内容のサマリ}

    {すべて完了した場合は、「すべて完了しました」等}
    ```
