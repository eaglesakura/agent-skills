# 計画ファイルフォーマッタ

## 概要

このコマンドは、 `/coding.*` コマンドの補助コマンドである。
現在の計画ファイルの内容を整理し、所定の書式に整えることにより、レビュアーや実装者の読解負荷を下げるものである。

## 入力値

* [ ] 対象の計画ファイル
* [ ] 現在の動作モード(択一)
  * 要件定義モード
  * 詳細設計モード

## ガードレール条項

* 書式整理のみが対象であり、実施内容・要件・詳細設計に関わる情報に変更が行われないこと

## 実施手順

### ステップ1: バリデーション

* 文脈から、下記を判断してユーザーに伝える
* 入力値が不定な場合は、処理を終了する

```markdown
対象ファイル: [{計画名}]({path/to/plan.md})
動作モード: {現在の動作モード}

* {フォーマットを実施可能です | 入力値が不定なため、処理を中断します}
```

### ステップ2: モードごとに適切なフォーマットを行う

#### 要件定義モード

* [requirements.md](../extra/coding/requirements.md) をロードする
* 書式に合わせて整理し、計画ファイルを更新する

#### 詳細設計モード

* [design.md](../extra/coding/design.md) をロードする
* 書式に合わせて整理し、計画ファイルを更新する
  * 作業手順は、 `ステップ1` から始まるようにインデックスを最適化する
