# 基本構成

## `main` ブランチ

* 開発中の最新コードを格納する
* 各オーナーリポジトリは、常に `main` の最新状態を基本とする

## `feature/id/{Issue番号}/{任意の名称}`

* 作業用のブランチ
* 各リポジトリの `Issue番号` に紐づいている
* この形式のブランチ名である場合、 `gh` コマンドでタスク内容を取得することが可能である

## `release/{リリースバージョン}/main`

* リリース用ブランチ
* バージョン名は慣習に基づいて決定される
  * アプリのようにバージョニングが明言している場合
    * `release/v1.0.0/main`
  * サーバーのようにバージョニングが明言されない場合
    * `release/v2025-12-31/main`
