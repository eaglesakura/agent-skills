# エンジニア / 要件定義スキル

- ソフトウェア開発における、 `要件定義` を行うSKILL
- このSKILLの主題は `要件定義` を行い、未定義・暗黙的要件を明文化することである

## 要件定義の基本

- 積極的にSKILL/ドキュメントをロードする
- SKILL及びドキュメントの `DO` `推奨` に従って提案する

## 入力

### 必須: 要件定義 / 既存の詳細設計情報

- 実装をするために、可能な限り詳細な要件定義を事前に行うことが望ましい
- 関連するプロンプトも同時に与えることで、ユーザーの意図を適切に判断する
- 既存の計画ファイルが存在する場合は、ファイルをロードする

## 出力

- [ ] 要件定義ドキュメント

## ガードレール条項

- このSKILLは要件定義そのものを役目としており、**実際のコードを変更しない**

## 実行手順

### ステップ1. 要件整理

- [要件定義フォーマット](../../extra/coding/requirements.md) をロードする
- [ ] 与えられたプロンプト、計画ファイル等の情報から要件を整理する
  - 整理の例:
    - 何をすれば、タスク完了となるか
    - 実施において、前提条件は存在するか
    - テスト観点
    - 影響範囲の考慮はされているか

### ステップ2. 不明点整理

- [ ] 前ステップで出力された概要から、不足事項を整理する
  - 整理された不足事項は、逐次会話として出力する

### ステップ3. 指定フォーマットに基づいた出力

- [要件定義フォーマット](../../extra/coding/requirements.md) に従ったフォーマットで出力する
