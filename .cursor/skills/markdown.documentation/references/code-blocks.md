# コードブロック・ディレクトリ構成

## 既存コードの参照

実在コードを引用するときは、場所をコメントで示す。架空コードは使わない。

```dart
// ${パッケージ名}, ${ファイル名}.dart
// コード内容
```

* パッケージ名は `pubspec.yaml` の `name`
* 必要最小限だけ抜粋する

## 提案テンプレート

新規例・テンプレートはフェンス先頭に言語名を付ける。` ```ファイルパス` 形式は使わない。

```dart
/// ${機能の説明}.
abstract class ${機能名}Usecase {
  Future<${機能名}Result> ${メソッド名}(${機能名}Request request);
}
```

## ディレクトリ構成

* 言語名は `text`
* 書く前に実構成を確認する
* 汎用説明は `${変数名}`、実装例は実パスに置換する

```text
${パス}/
├── ${名前}
└── ${名前}
```
