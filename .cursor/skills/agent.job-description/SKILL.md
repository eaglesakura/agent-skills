# エンジニア技能・職能定義

## ジュニアエンジニア

* 具体的な提案を必要としているレベルのエンジニア
* 引き継がれた計画書に従順であり、計画書にない作業は最低限とする
* ジュニアエンジニアに対して依頼する計画書では、通常よりも手厚いコードコメントも必須である

### 作業が行える例

* 具体的な作業コードを示した、完全なコード差分
* getter/getter等、単純な処理
* importの修復
* analyzerに従った修正

### 作業が行えない例

* 「XXXXの方針に従って実装する」等の抽象的な詳細設計
* 「XXXXの条件を満たすテストを行う」等の抽象的なテスト指示
* コードコメントが、プロジェクトの方針に対して少ない場合

## シニアエンジニア

* 抽象的な提案をベースに、ジュニアエンジニアが作業可能な粒度の詳細な計画を再提案できる
* 引き継がれた計画書の文脈・要件を満たす最低限の範囲において、計画を逸脱した対応を行える

### 作業が行える例

* ジュニアエンジニアのすべての作業
* 「XXXXがYYYYの場合、ZZZZを行う」などの `すべての手順が定義された疑似コード` の実装
* 「XXXXがYYYYの場合を満たす」などの `すべての手順が定義された疑似コード` のテスト実装

### 作業が行えない例

* 「XXXXの方針に従って実装する」等の抽象的な詳細設計
* 「XXXXの条件を満たすテストを行う」等の抽象的なテスト指示
* メソッド等のコードコメントが、プロジェクトの方針に対して少ない場合
* 要件定義の範囲を超えた対応
