# coding.execute 作業指示テンプレート

`/coding.execute` が Sub Agent に渡す作業指示の正本である。
プレースホルダ（`{...}`）は実行時に埋める。

## ジュニアエンジニアへの作業指示

```markdown
# 作業指示: [{作業ファイルタイトル}]({path/to/plan.md})

## 作業内容

* {ステップXXXX} を完了させる
* {ステップYYYY} を完了させる

## 品質確認

* 修正したコードに関連するコードコメントの追加・更新を行う
* Formatter, Analyzerによる機械的な品質保持を行う

## 結果返却

プロジェクトのチェックリストルールに従い、状態記号を返却する。

- [ ] {ステップXXXX}
- [ ] {ステップYYYY}
```

## ジュニア失敗時のシニア引き継ぎ

```markdown
# フォローアップ指示: [{作業ファイルタイトル}]({path/to/plan.md})

* ジュニアエンジニアが作業を完遂できなかった
* 作業を継続し、完了させること

## 作業内容

* {ステップXXXX} を完了させる
* {ステップYYYY} を完了させる

## 品質確認

* 修正したコードに関連するコードコメントの追加・更新を行う
* Formatter, Analyzerによる機械的な品質保持を行う

## 結果返却

プロジェクトのチェックリストルールに従い、状態記号を返却する。

- [ ] {ステップXXXX}
- [ ] {ステップYYYY}
```

## 品質担保（シニア）

```markdown
# 品質担保指示: [{作業ファイルタイトル}]({path/to/plan.md})

## 作業内容

* 対象ファイル一覧を確認し、コード品質の確認を行う
  * コメント粒度・内容が、プロジェクト方針と一致すること
  * `/coding.comment` コマンドも適宜参照する
  * コメント内容が適切でない（古い内容）の場合は、適切に更新すること
  * Formatter, Analyzerによる機械的な品質マネージメントを実施すること

## 品質確認

* 修正したコードに関連するコードコメントの追加・更新を行う
* Formatter, Analyzerによる機械的な品質保持を行う

## 結果返却

プロジェクトのチェックリストルールに従い、状態記号を返却する。

- [ ] {path/to/file}
  * {Formatter, コメント追従, 等の作業内容}
```
